# ADR-001 : Project Philosophy

Status: Accepted

Date: 2026-07-08

---

## Context

나침은 대학생을 위한 커리어 운영 플랫폼이다.

프로젝트의 목표는 최신 기술을 사용하는 것이 아니라,
학생에게 가장 큰 가치를 가장 빠르게 제공하는 것이다.

학생 1인 개발 프로젝트라는 현실적인 제약도 고려해야 한다.

---

## Decision

서비스의 핵심 경쟁력은

- 데이터
- 데이터 분석
- 비즈니스 로직

으로 정의한다.

공통 기능은 적극적으로 외부 서비스를 활용한다.

---

## Consequences

### 장점

- 빠른 개발
- 유지보수 단순화
- 핵심 기능에 집중 가능

### 단점

- 외부 서비스 의존성 증가

그러나

핵심 데이터는 항상 내부 DB에서 관리한다.
